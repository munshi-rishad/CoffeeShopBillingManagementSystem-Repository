# Coffee Shop Billing Management System

Java Swing based coffee shop ordering and billing management system.


## Run

1. Open the project in Eclipse, IntelliJ IDEA, or another Java IDE.
2. Add the `src` folder as the source folder.
3. Keep the project root as the working directory so the `assets/...` paths resolve correctly.
4. Run `Start.java`.

The existing UI, images, and project flow have been preserved. Resource files were only organized and renamed according to their actual use.
